# HR-направление JobSonar

Отдельная папка под всё, что касается HR-бота и поиска HR-вакансий: исследования
источников, замеры, черновики спек. Код бота остаётся в `web/` (main.py, hr_*.py,
scoring.py, employers.py) — здесь только материалы.

```
hr/
├── research/   — разборы источников (что можно тянуть, чем, какой ценой)
└── data/       — выгрузки и замеры (сырые данные для решений)
```

## Текущие источники HR-бота

| Источник | Статус | Как берём |
|---|---|---|
| hh.ru | в проде | парсинг SSR-стейта, 3 гео-оси + `professional_role`, см. корневой README |
| Сетка (setka.ru) | исследуется | [research/setka.md](research/setka.md) |
